# 未央宣传组运营自动化

在 Windows / macOS 上结合 Docker 专用浏览器、Python 脚本与执行 agent，读取 WPS 推送预约、核对秀米收稿、整理独立副本、按顺序同步到公众号草稿箱，并通过企业微信报告结果。最终发布由人工完成。

## 工作流程与边界

1. 实时读取 Asia/Shanghai 当天完整预约、头条、源行序及备注；登录或读取失败不能当作无预约。
2. 核对常用秀米账号和正确稿件，保留预约标题、实际标题及确认同稿的证据。
3. 按账本复用独立副本，修正已验证的基础格式，保存后重开核对正文、图片、样式及封面。
4. 头条置首，其余按预约表行序组合；同步仅提交一次。未知结果先查平台，禁止清账本重跑。
5. 发送真实企业微信结果，保存回执、检查点、用量与交接材料。

“转存好”平台标签按使用者要求关闭，防重以私有账本为准。常态运行目标为北京时间 17:00；仓库文档不代表某台电脑或某个会话的调度已启用，部署时须核对实际任务。当前不因文档更新修改调度。

## 开始与接手

先阅读 [AGENTS.md](AGENTS.md)，再按 [环境安装](docs/setup.md) 和 [专用浏览器](docs/browser.md) 准备环境。执行与接续以 [完整流程入口](docs/full-runner.md)、[每日运行](docs/daily-run.md) 和本机既有账本为准。

真实业务同时只允许一个执行者。部署沿用已有容器及热替换，不自行重建容器、增加端口、删除浏览器卷或清理登录状态。登录、验证码、协议及新增授权由使用者处理。
