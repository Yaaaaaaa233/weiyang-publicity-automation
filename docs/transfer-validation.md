# 跨账号转存验证

日期：2026-10-01。状态：单篇合成测试稿通过跨账号接收、独立副本找回及刷新后内容核对。

使用者已确认日常接收、转存稿件的秀米账号，并人工完成登录。执行者根据首页可见账号名称核对目标身份。本轮仅操作先前保存的合成测试稿，没有修改真实业务稿或执行公众号发布。

## 实际完成的流程

1. 来源编辑器“更多”→“另存图文给其他用户”→“另存二维码”，生成官方接收入口。二维码从截图离线识别，接收地址保存在本机。
2. 退出来源账号，由使用者在专用浏览器登录目标账号；核对可见身份后打开已记录的接收页面。
3. 页面正确显示来源和测试稿标题。点击一次“存入我的秀米”，平台提示“图文保存成功”，目标列表出现测试副本。
4. 打开副本的临时预览，明确刷新后读取标题、作者归属及正文，并与来源快照比较。
5. 从官方首页进入目标账号“我的图文”，按测试稿标题过滤。列表找到唯一测试结果，其编辑链接与来源稿件链接不同。
6. 用列表实际提供的编辑入口重新打开独立副本，明确刷新编辑器，再打开预览；最终正文检查再次通过。
7. 完成独立转存任务的检查点，释放执行者租约并导出交接记录。

## 已观察到的限制

- 预览“分享”标签此前提示尚未审核，分享二维码和链接不可用；本轮没有申请分享审核。使用“另存二维码”接收路线完成转存，不需要本轮申请该分享审核，也没有继续同步 App 审核。
- 个人另存入口要求接收账号绑定的手机号或邮箱。本轮未选择联系人或填写接收联系方式。
- 临时预览界面说明链接短期会失效。因此持久定位保存的是目标稿件库提供的编辑入口，不能只把临时预览链接作为交接依据。
- 页面有异步加载：命令返回与可见预览出现可能存在时间差。遇到空链接、缺少 iframe 等情况先重新观察；不能据此重复接收。
- 本轮不验证接收地址的有效期、重复接收规则、团队权限、真实封面规范、公众号同步或发布。
