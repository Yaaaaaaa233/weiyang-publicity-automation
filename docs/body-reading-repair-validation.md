# 正文读取修复验证

2026-10-12，Mac Codex 接手。Windows r9 的真实运行因正文作用域发现失败而返回整页，触发 `truncated_page`；不是缺稿。

## 实现

正文节点先通过快照的 class 字段定位；其位置路径末段就是该节点，父级由路径长度推导，不再从路径查找类名。优先用正文与标题位置路径的共同祖先，只有元数据路径不可得时最多尝试 12 个祖先，真实路径中的 `html > body` 也被排除。标题与正文必须同时存在；正文、段落、图片、封面及截断验收继续使用既有规则。

正文采集创建的窗口在成功或失败后均尝试核对并关闭：先切换到本次创建的 handle，再读取实时 URL 并核对稿件 ID，最后使用带 URL 与返回窗口校验的关闭命令。身份变化则保留窗口；清理失败留私有记录，不替换原始采集故障。

- JavaScript 契约测试执行仓库实际 `path()` 函数，以模拟 DOM 的标签、父子及兄弟关系产生位置路径，再交给 Python 发现作用域。这不是完整浏览器 DOM 验收；Windows 实测仍需进行。未安装 Node 的环境会明确 skip 此项，不能把 skip 记为已验证。
