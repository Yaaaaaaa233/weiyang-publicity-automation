# 秀米基础稿件闭环验证

日期：2026-10-01。设备：Apple 芯片 Mac，专用 Docker Chromium。

## 本轮结果

使用者完成专用浏览器里的人工登录后，新建一篇空白合成测试稿，输入标题及三段正文，读取正文，保存并重新打开核对。随后重启浏览器容器，建立新会话，根据本机记录找回同一篇稿件，标题与三段正文仍一致，未要求重新登录。

本轮没有操作现有业务稿件。测试稿保留在当前秀米账号中，未发布、未导出、未转发。

## 实际操作与限制

本轮混合使用 Computer Use 操作 noVNC 画面与项目命令接口。标题和正文由命令接口输入，正文由命令接口读取；最终保存由命令接口坐标点击。远程桌面转发点击工具栏时没有观察到预期结果，因此保留这项链路限制。

编辑器保存是异步过程。点击后短时间内仍可能显示新稿 URL；本轮等待平台生成已保存定位后才执行重开验证。命令返回成功只说明动作被执行，不能单独证明稿件已保存。

重启后的恢复由本轮验证程序显式读取 JSON 定位再打开页面。该阶段尚未提供任务数据库；后续已补充本地 SQLite 账本及执行者租约，见 `docs/tasks.md`。自动重试策略或独立模型循环仍未提供；这不等于完整业务任务已支持自动断点续跑。下一位 agent 可以读取记录并重新观察，但仍需实际交接验收。

## 后续验证：预览、图片与报告

继续使用同一合成稿。通过 Computer Use 选择秀米的单图模板并插入正文，点击保存，随后用 WebDriver 明确刷新页面，再打开预览核对。

- 主图原始尺寸为 1080×559。模板另外包含两个装饰图片元素，各为 363×579，并有两个 CSS 背景样式。
- 保存前后的三个图片元素来源、原始尺寸及两个背景样式一致；所有图片元素 `complete` 为真且原始尺寸大于零。
- 标题、原有三段正文及模板文字在刷新后的预览中保留，截图显示图片与模板排版正常。
- 只读读取工具支持指定 DOM 区域及 iframe，内容取回到本机 JSON。顶层页面的模板库图片没有混入文章区域统计。
- 预览 `body` 中的阅读数会变化，整页文本比较曾因此失败。实际内容核对改为 `.tn-article-body` 正文区域及明确的预期文本；不把页面阅读数变化当作稿件变化。
- 通用报告命令在合成规则下通过 9 项检查。构造原始宽度为零的图片、缺失验证文字和截断节点三个异常时，都返回检查失败。
- 检查工具在 iframe 内遇到不存在的读取选择器后返回失败，并恢复到顶层页面；后续命令没有遗留 frame 上下文。

这里验证的是一个模板的保存与显示，不是所有图片或复杂排版。CSS 背景只记录样式，没有单独断言资源加载。没有上传私人素材、绑定账号、执行转存或发布。当前账号不是日常转存账号，正式转存权限和流程仍需换账号验收。
